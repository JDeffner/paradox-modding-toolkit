# Paradox Modding Toolkit 0.6.0

The features previewed in 0.5.5 are now on the stable channel, with support for CK3's Silk & Silver update.

- **CK3 Florin.** Get completion, hover help and navigation for trade goods, districts, roads and prosperity, plus the Florin Workshop tag.
- **Clearer, safer editing.** See what script symbols mean at a glance. Localization, Event Graph and Dynasty Tree edits better preserve comments and unsaved work.
- **Searchable settings and Wiki.** Find settings, see where they are saved, and jump directly to game references.
- **DDS and Workshop tools.** Match a reference texture's mip levels, inspect and export individual levels, and keep separate Workshop listings for older game versions.
- **Experimental Compatch.** Review and restore supported game-version migrations. Enable it in Toolkit Settings to try it.

Deep validation for Florin requires a Tiger-compatible validator that supports CK3 1.21. The built-in script checks work independently.
