# Paradox Modding Toolkit 0.3.5 (beta, pre-release)

0.3.5 is the 0.4.0 feature set, released early so problems surface before
0.4.0 makes it official. Two headline features and a lot of connecting
tissue.

**Publish to the Steam Workshop from the editor.** The Workshop panel
uploads through your running Steam client: no launcher, no web form, no
password typed anywhere. The listing (description, per-language titles and
descriptions, changenotes) lives as plain files next to your mod, so it
diffs and versions like code. New items are created private.

**The Examples Wiki became the reference it wanted to be.** Search all
25,000+ names the toolkit knows: triggers, effects, event targets,
modifiers, datafunctions, data types, keywords, scope words, and now your
own variables and lists. Articles show real vanilla code inline, link to
each other, and answer the question modders actually ask: open the `faith`
target and see every trigger, effect and target usable from a faith scope.
Back and forward work like a browser, mouse side buttons included. Every
hover in the editor links straight to the matching article.

Also in this build:

- **New Mod and the mod projects layout.** Scaffold a mod where git and
  Workshop files live next to the content instead of inside the upload.
- **Run the game with F5.** Per-game launch presets through Steam, debug
  flags on by default.
- **Custom calendars.** Total-conversion mods declare `px.calendar` once
  and every script date shows its display form: `4000.1.1` reads "1 AD".
- **A Wiki button in the Project panel.** Image guidelines, every
  diagnostic explained, and the reference launchers in one searchable view.
- **One icon language.** Breadcrumbs, outline, symbol search, hovers and
  completion now draw identical glyphs, and the four list kinds are finally
  distinguishable.
- **Help where you need it.** Every panel has a "?" that explains its
  features; tooltips went back to being one line.

Full detail is in the changelog. If something breaks, say so on the
Discord: that is what this pre-release is for.
