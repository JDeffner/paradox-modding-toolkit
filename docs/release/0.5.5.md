# Paradox Modding Toolkit 0.5.5 prerelease

0.5.5 is an opt-in preview of the upcoming 0.6.0 update, with changes since 0.5.0.

- Updated CK3 Crozier references, clearer script highlighting, Wiki game switching and automatic article edit dates.
- Shared localization rules, per-mod settings and safer Event Graph, Dynasty Tree and creator saves that preserve existing work.
- DDS conversion with full or partial mip chains, reference matching, stored-mip previews and revised image guidance.
- Experimental CK3 faith and portrait-mask migrations with reviewed diffs, reversible writes and faster file scans.
- Legacy Workshop listings from archived mods, compatibility tags and reusable gallery image preparation.

Compatch remains experimental and off by default. The migration SDK and mod-to-mod gameplay validation remain unfinished. Province Painter and Artifact Creator are not included. CK3 migration testing covers the documented Lantern fixture, not arbitrary mods or saves.

In VS Code, open the extension page and choose **Switch to Pre-Release Version** to try it. Report problems with the game version and reproduction steps.
