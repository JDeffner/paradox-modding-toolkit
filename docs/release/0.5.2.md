# Paradox Modding Toolkit 0.5.2

This stable release separates shared mod rules from personal settings. Mod Compatibility and Compatch remain experimental and are off by default.

- With **Experimental features** enabled, use **Compatibility Patch** to maintain a patch for an ordered set of CK3 mods. Save contribution and field choices, review affected decisions after source updates, preserve independent output edits and restore journaled writes. Unsupported cases remain manual work.

- Open **Toolkit Settings** from Project > Settings > All settings. Search one catalogue, with save destination and active-source labels beside each setting. **Details** contains longer explanations and destination choices; question-mark help appears on hover or keyboard focus. Unsaved drafts stay available when you change contexts or views.
- Share mod rules through `.px-toolkit/project.json`. Personal paths stay in your VS Code User profile, with separate game and workspace bindings. Existing settings upgrade on trusted startup; **Upgrade Toolkit Settings** retries incomplete work. Legacy files remain available, and conflicts are reported.
- Create, edit and override localization with file placement that follows the mod's existing layout and per-mod author defaults. Vanilla Explorer actions can copy a file or create its folder path in the selected mod without replacing existing work.
- Edit CK3 character history in **Dynasty Tree** without losing comments, spacing, trait groups or detailed death blocks. Choose death reasons and quotation preferences. Stale forms keep your draft and leave newer source edits intact.
- Create a separate **legacy Workshop item** for a game version. Its first upload sends the current project files. Later uploads change Workshop information only. Stalled uploads can stop waiting without an automatic retry.
- Convert DDS images with a full or custom mip chain, or match a reference texture's format and mip count. Inspect stored mip levels and export the displayed level. Texture arrays, cubemaps and volume textures are rejected by conversion instead of silently losing surfaces.
- Get Crozier documentation and navigation for standalone faiths, rites and tenets, with older nested faiths still supported. The Project panel keeps longer mod lists reachable.
- With **Experimental features** enabled, use **Mod Compatibility** to follow exact game-version routes, load reusable notes and recipes, answer required choices, review changes and restore applied steps. CK3 1.19.0.6 to 1.20.0.2 includes faith/rite and portrait/clothing mask mip migrations. You can load several contribution files or a folder at once.

Legacy uploads use the files currently in your project, not an archived copy from that game version. Check the selected files before the first upload. Rename remains unavailable for faiths and laws while indirect reference coverage is incomplete.

Migration checks establish source structure and file preservation, not gameplay compatibility. No Crozier-compatible Tiger validator is available. Test the migrated mod in the target game; unsupported cases and uncovered version transitions require manual work. DDS actions against large reference installations can take over a minute; progress and cancellation are available while inputs are being read.
