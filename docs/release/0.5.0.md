# Paradox Modding Toolkit 0.5.0 (beta)

- Review game updates in the new Compatch panel. Compare old game data, new game data and your mod, resume named sessions, and work through a review queue. CK3 includes event and localization-key comparisons across files.
- Preview clean updates, resolve conflicts in an editable result, and apply individual localization keys. Review status, validation against the selected new game data and recorded runtime tests remain separate.
- Use context menus on files, definitions, overrides and localization references. Actions follow the selected source. Event Graph, GUI Editor and Coat of Arms Designer also gain native source menus and keyboard improvements.
- Open BBCode Preview from VS Code's editor selector. Switch back to source or preview beside it, including unsaved edits.
- Use a smaller Project dashboard with workspace health, visible mod focus and All Tools. Setup notices are consolidated and optional; walkthrough steps reflect readiness.
- Reduce repeated localization parsing and keep coverage scans and game-log bursts responsive. Worker-based parsing is deferred pending further testing.

Compatch comparisons do not establish in-game compatibility. Target validation needs a compatible validator and the selected full game installation; a game-data snapshot can still be compared. Victoria 3 and EU5 use file comparisons where semantic matching is unavailable.

Includes `@px-lsp/server` 0.3.6 and `@px-lsp/protocol` 0.2.6.
