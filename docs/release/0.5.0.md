# Paradox Modding Toolkit 0.5.0

- Create or find your mod from Start Here, with a clearer tutorial and visible files after creation.
- Get better suggestions, navigation and renaming, including unsaved edits.
- See Problems update when related files change, with less repeated work on large mods.
- Convert batches of images and reach more tools from right-click menus.

Compatch is planned for 0.6.0.
