# Use the Project view

Open the Paradox icon in the Activity Bar. **Project** shows the active game and selected mod. **Follow** tracks the active editor. Use the mod list inside **Project** to select a mod to **Pin** the views to it, or use **New Mod** to create a project. The section scrolls when its rows exceed the available space.

Use **Create > New Content** to add a script file. **All Tools** in the Project title bar opens a searchable list of supported tools, including rows hidden with **Customize** beside it. Click **PX Toolkit** in the status bar for setup and health checks; run **Paradox: Validate Mod** from the Command Palette for validation.

Project groups **Workspace Mods**, **View**, **Create**, **Publish** and **Info** in one scrolling view. It remembers each group you expand or collapse. The **View** group contains **Scope inlay hints**, an optional display of inferred target types in script. It is off by default. **Test & Troubleshoot** contains the error-log watcher, vanilla diagnostics and supported tiger controls. **Paths** shows effective detected and configured folders; select a path to change it.

Right-click a definition in **Mod Overview**, a localization key or a file in Explorer to find actions for that object. Keyboard users can select it and press **Shift+F10**.


Use **Show Event Graph** to follow event links, or **Show Mod Report** for an overview of the selected mod.

**Project**, **Utils**, **Test & Troubleshoot** and **Paths** can each be moved, collapsed or hidden with the native view controls. Drag a view by its header to arrange your workspace. Utils contains batch image conversion and the BBCode converters. Right-click a supported file or folder to find applicable actions labelled **PX:**.
