# Find your tools without memorizing commands

## PX Toolkit: work on the selected mod

Select the **PX icon** in the Activity Bar. **Project** shows the active game and mod. **Follow** tracks the active editor; select a mod to **Pin** the views to it. Workspace Mods scrolls after five rows.

- **Create** adds content through templates and the visual creators supported by your game.
- **View** opens tools such as Event Graph and GUI Editor where supported.
- **Settings** controls scope inlay hints, suggestion verbosity and hover detail. Defaults stay unchanged until you choose something else.
- **Publish** contains the Workshop tools. You do not need to publish a mod to test it locally.
- **Info > Getting Started** returns to this tutorial.

**All Tools** in the Project title bar searches the tool catalogue. **Customize** controls which rows appear. **Utils** contains image conversion and BBCode tools; **Test & Troubleshoot** contains validation and game-log controls; **Paths** shows which folders are actually in use.

## Explorer: inspect files and definitions

Below the file tree, expand **Mod Overview** to find definitions or **Localization Coverage** to see missing translations. **Problems by Type**, **Overrides & Conflicts** and **Dependencies** start hidden; enable them from Explorer's view menu when you need them.

Right-click a file or definition for actions on that exact source. You can move, collapse or hide views with VS Code's native controls. Existing custom placements are preserved.

For the shortest route, press F1 and type **Paradox** or right-click the file you are working on.
