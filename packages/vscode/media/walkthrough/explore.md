# Take the tour

Open one of your event files and try:

- **Hover** `add_gold` → description and supported scopes
- **Ctrl+Alt+I** on an empty line → inserts a skeleton measured over the game's own definitions (a whole event, or one `option` block), with tabstops to fill in
- **Type on a blank line** in an event file → `new event` and `option block` sit at the top of the suggestions
- **Type** inside a `trigger = { }` block → only triggers are suggested; inside `immediate = { }` → only effects
- **F12** on a scripted effect → jumps to its definition (yours or vanilla's)
- **Look right** of a `title =` line → the localized text appears inline; use the lightbulb to edit it without leaving the file
- **F12 in a localization yml** → jumps back to where the key is used in script
- **Paradox Localization: Add Language (scaffold files)** → scaffolds a new language from your english files, with english overlaid while you translate

The status bar item (bottom right, "PX Toolkit") shows data health at a glance — click it to re-run setup.
