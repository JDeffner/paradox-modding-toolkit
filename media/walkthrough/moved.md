# This extension has moved

The CK3 Modding Toolkit continues as the **Paradox Modding Toolkit**
(`JDeffner.px-toolkit`). It is the same tool, further along, and it now speaks
Crusader Kings III, Victoria 3 and Europa Universalis V.

This listing is deprecated. It gets no more fixes and no more features.

**Install the new one, then uninstall this one.** Your mod files are untouched.
Settings move with a rename: every `ck3.*` key becomes `px.*` (`ck3.gamePath` →
`px.gamePath`), commands are prefixed **Paradox** instead of **CK3**, and the
inline suppression comment is `# px:ignore` instead of `# ck3m:ignore`.
